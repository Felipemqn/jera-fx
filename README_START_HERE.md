# Start here

1. Create a folder such as `C:\jera-fx`.
2. Copy the contents of the phase-1 seed package into that folder.
3. Initialize git in the folder.
4. Open the folder or repo in Codex.
5. Paste the prompt from `JERA_PHASE1_CODEX_PROMPT.txt`.
6. Wait for the planning output.
7. Bring the planning output back to ChatGPT for review before approving implementation.
